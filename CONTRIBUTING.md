# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Keep personal data and credentials out of fixtures and logs.
3. Run `python -m unittest discover -s tests -v`.
4. Open a pull request describing the behavior change and validation performed.

Recruiter outreach must remain review-before-send. Changes that guess email
addresses, scrape personal contact details, or remove the daily send cap will not
be accepted.
